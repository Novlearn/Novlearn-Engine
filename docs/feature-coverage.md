# Matrice de couverture fonctionnelle

État local inspecté le 10 octobre 2026, au-delà de la seule génération. Cette matrice couvre la demande et les sources accessibles, **pas l'intégralité inconnue du catalogue de production**. Les tests cités sont présents dans ce dépôt ; le bilan de leur exécution est dans [progress.md](progress.md). Les suites voisines et navigateur ne sont pas exécutées dans cette mission.

## Lecture et sources

Statuts : **IT** implémenté et testé dans le sous-ensemble décrit ; **IP** implémenté mais preuves insuffisantes pour la garantie visée ; **P** partiellement implémenté ; **D** prévu et documenté, exécution absente ; **A** absent sans capacité annoncée ; **HP** hors périmètre du cœur ; **?** inconnu faute de sources/preuves. « Observé externe » décrit un code voisin, sans certification ni intégration native. Un test de rejet ne prouve jamais un support positif.

Priorités : **P0** invariant ou fondation avant capacité dépendante/adoption officielle ; **P1** premier périmètre étendu ou parcours pilote ; **P2** complément après besoin explicite. Aucun ordre de priorité n'autorise le lancement d'un lot.

## Conclusion de couverture

Les Lots 1–4 sont livrés dans leur périmètre borné ; Lot 5 natif ajoute substitution/calcul d'attendu/projection d'une question entière. Les fondations de confiance sont documentées/testées localement, mais correction, multiquestion, groupes/calculs de variables, éléments étendus, isolation forte et adoption officielle restent absents. Les fonctions applicatives ont un responsable externe ; les types historiques inconnus requièrent des sources supplémentaires. Les compléments de [roadmap](roadmap.md) ne recommencent pas les lots livrés.
