# Archives documentaires

Ces documents conservent les observations, propositions, bilans et autorisations
de leurs dates. **Ils ne sont pas la référence actuelle ni une liste de tâches
à relancer.** Les exemples expérimentaux n’utilisent souvent plus les API admises.
Lire [l’index actuel](../README.md), [les capacités](../features.md) et
[la procédure de reprise](../progress.md).

| Archive                                                 | Information unique conservée / remplacement actuel                                                         |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [analysis](analysis.md)                                 | Sources initiales, observations externes et arbitrages des analyses en lecture seule                       |
| [architecture-review](architecture-review.md)           | Audits successifs, risques historiques et revue finale M12 ; profils actuels dans features                 |
| [consolidation](consolidation.md)                       | Correspondance des contrats/modules supprimés et justification ADR 008                                     |
| [exercise-engine-vision](exercise-engine-vision.md)     | Cadrage initial ; rôle actuel dans README/architecture                                                     |

| [functional-specification](functional-specification.md) | Inventaire détaillé des anciens types et propositions ; contrats réels dans architecture/features          |
| [test-strategy](test-strategy.md)                       | Bilans de tests par lot ; maintenance actuelle dans development                                            |

Les douze archives reçoivent un repère explicite et des liens relatifs ajustés.
Les textes historiques ne sont pas réécrits pour leur attribuer rétrospectivement
des capacités. Les ADR utiles restent dans `docs/adr` avec statut **Active** ou
**Superseded** ; les décisions remplacées restent consultables à leur emplacement.
CDC, corpus, fixtures et preuves JSON/images restent à leurs chemins d’origine.
